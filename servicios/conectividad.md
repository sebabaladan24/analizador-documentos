## Descripción
Enlaces de datos dedicados o compartidos entre las sedes del cliente y/o
hacia la infraestructura propia (MPLS, internet dedicado, punto a
punto).

⚠️ COMPLETAR CON DATOS REALES antes de usar este archivo para generar
propuestas — los valores marcados "X" son placeholders.

## Especificaciones técnicas
- Tecnología: MPLS / fibra dedicada / radioenlace (indicar cobertura geográfica)
- Ancho de banda: desde X Mbps hasta X Gbps, simétrico/asimétrico
- Redundancia: enlace de respaldo disponible sí/no, tiempo de conmutación
- Latencia garantizada: hasta X ms dentro de la red propia

## SLA
- Disponibilidad: 99.X%
- Tiempo de respuesta ante incidentes: X horas

## Cuándo ofrecerlo
Cliente que necesita conectar múltiples sedes entre sí o con la
infraestructura propia, con ancho de banda y latencia garantizados
contractualmente (no "mejor esfuerzo").

## Cuándo NO ofrecerlo
Si el requisito de ancho de banda/latencia excede lo que la
cobertura geográfica actual puede garantizar — señalarlo como
requisito sin cobertura en vez de forzarlo.
